BACKEND (api/)
--------------
Database / models
  models/favorite.js            NEW  Favorite join model. Unique (userId, courseId), FK cascade delete
                                     to Users and Courses, index on courseId.
  models/course.js              MOD  Indexes on title and userId. belongsTo FK renamed 'userid' -> 'userId'
                                     (casing mismatch with User.hasMany, per design). Course.hasMany(Favorite).
  models/user.js                MOD  User.hasMany(Favorite).
  models/index.js               MOD  DB_STORAGE env var overrides the sqlite file (used by tests).
  migrations/20260107000000-add-favorites-and-indexes.js
                                NEW  Creates Favorites + the 4 indexes. Idempotent (safe alongside the
                                     sequelize.sync() that app start-up runs). Has a down().
  seed/data.json                MOD  4 users, 30 courses (was 2 / 4), 16 favorites. Keyword-diverse titles.
                                     Alex Rivera has 7 favorites across 3 different owners.
  seed/database.js              MOD  Creates Favorites table + indexes, seeds favorites, staggers
                                     Courses.createdAt (one day apart) so "newest" sort is meaningful.

Routes
  routes/courses.js             MOD  GET /api/courses now returns { items, meta }.
                                       q          trimmed, case-insensitive contains on title OR description
                                                  (LIKE wildcards in user input are escaped)
                                       ownerId    positive int; otherwise 400 {"errors":["Invalid ownerId"]}
                                       sort       newest (default) | title_asc; invalid -> newest
                                       page       invalid/<1 -> 1; page past the end -> last page
                                       pageSize   default 12, clamped 1..50
                                       meta       totalCount, page, pageSize, totalPages, sortApplied,
                                                  qApplied, ownerIdApplied
                                     GET /api/courses/:id: proper 404 {"error":"Course Not Found"};
                                       adds isFavorited (false when anonymous).
                                     NEW POST   /api/courses/:id/favorite   (auth, 204, idempotent, 404)
                                     NEW DELETE /api/courses/:id/favorite   (auth, 204, idempotent, 404)
  routes/users.js               MOD  NEW GET /api/users/me/favorites (auth) -> { items }, same shape as list.
                                     NEW GET /api/owners (public) -> users who own courses. Not in the
                                     design doc, but the owner dropdown needs it: with pagination the
                                     client cannot derive the owner list from the current page.
  middleware/auth-user.js       MOD  optionalAuthenticateUser: sets req.currentUser if credentials are
                                     valid, never rejects (used by course detail).
  app.js                        MOD  Exports app; only listens when run directly, so tests can import it.
  package.json                  MOD  Scripts: "migrate", "test".

SELENIUM / JUNIT 5 E2E SUITE (selenium-tests/)
----------------------------------------------
  Based on the JSON from the test automation agent, but adapted to the real app. Differences:
    - pom.xml: defaults for baseUrl/apiBaseUrl/headless/browser/pageSize (the pasted pom passed the
      literal text "${baseUrl}" to the tests when no -D flag was given); dropped unused jackson dep;
      added slf4j-simple; compiler "release 17".
    - Selectors match the actual markup (a.course--link cards, #catalog-search / #catalog-owner /
      #catalog-sort, nav.pagination, .empty--state, button.favorite--toggle[aria-pressed]). The pasted
      ".grid-33" and "h2 Courses" selectors do not exist in this app, and "a[href^='/courses/']" would
      also match the "New Course" tile.
    - ApiClient.getCourses takes Map<String, ?> (the pasted Map<String,Object> would not compile with
      Map.of("page", 1)).
    - Safe test data: the pasted ownership test updated items[0] (Sally's own course after the new seed,
      so it would succeed) and the cascade test deleted seeded data. Ownership/favorites tests now create
      and delete their own throwaway course via the API; Joe's seeded favorites are never touched.
    - Stronger assertions: UI titles/order are compared with the API for the same query, sortApplied is
      checked strictly, "no full refresh" is proven with a JS marker, invalid page is checked to be
      normalised out of the URL (the pasted test expected "page=" to stay in it).
    - CatalogPage waits for results to be re-rendered (stalenessOf) instead of reading old cards.
  28 tests: US-001 x8, US-002 x7 + ownership x4, US-003 x9.
  Run: cd selenium-tests && mvn clean test -Dheadless=true  (needs API :5000 + UI :3000 on a freshly
  seeded DB; see selenium-tests/README.md). Passed 3 of 4 full runs 28/28; the other run had 1 Chrome
  renderer crash ("session deleted... Unable to receive message from renderer") before adding
  --disable-gpu/--disable-extensions and a 30s page-load timeout; 2 clean runs since.
  Verified against a throwaway seeded DB (not the tracked one); fixtures cleaned up (still 30 courses).
